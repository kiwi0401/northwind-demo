# Team context

This folder is the team's shared context for SignalPilot.

- `AGENT.md` is the brief every chat reads first: what Northwind is, which marts to use, and the rules for most questions.
- `metrics/<topic>/<metric>.yml` holds one governed number per file, with its definition, traps and a SQL hint.
- File and folder names are lowercase words joined by hyphens.
